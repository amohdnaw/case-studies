11 · Data integrity6,000 charts × 1,500 plants · synthetic

The machine was never recorded. The chart name knew.

One SPC chart in six has no machine ID, so the report reads the machine from the chart name and scores that guess on charts that have one. On a synthetic plant the score held when blanks were random, and read 2 to 3 times low when they sat in hand-typed charts. A check on the names alone caught the difference.

I audited my own trading system, and killed my best result

A paper-trading log showed +0.48%/trade and an iid bootstrap called it significant. Day-clustered inference, an always-long baseline on identical instances, and a confidence score at r = −0.015 said otherwise. A null result, honestly reported, with the runnable notebook.
